Guild Settlement Credentials

A signed, chain-agnostic receipt that a Guild task settled — plus this page's own in-browser verifier, so nobody has to trust the list below on its own say-so.

Draft slice, not a decision. This package ships code, tests, and one UNSIGNED demo credential. Nothing here is signed with a real key, and this page is not linked from anywhere live. See ../README.md for what this is and is not.
Verification runs entirely in your browser (WebCrypto Ed25519 + a JCS canonicalizer) — credentials.json is fetched once, nothing is sent anywhere. Source: packages/settlement-credential.
